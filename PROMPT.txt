盘形凸轮把转角变成从动件的升程。规律不是随手写的多项式，而是几条具名配方：余弦（简谐）、摆线、等加速等减速。调用方点名一条配方，给出升程 h、升程角 β、角速度 ω，服务沿转角给出位移 s、速度 v、加速度 a、跃度 j，并核对接头处该连续的量是否连续。完整一周还可以接远休止、回程、近休止，拼成一条循环。范围限定在凸轮从动件运动学，仅经 HTTP 提供规律档与曲线。

无因次时间 T 等于当前升程段转角除以升程角，升程段里 T 从 0 走到 1。余弦：s 除以 h 等于 1 减 cos(πT)、再除以 2。摆线：s 除以 h 等于 T 减去 sin(2πT) 再除以 2π。等加速等减速：前半按 T 的平方升，后半对称减速，中点必须切换；不切换的话终点位移对不上 h。h 必须为正。β 必须为正且小于一周；角度单位全程同一套，钉死为度或弧度并在结果里写明。ω 必须为正。未知规律名在求曲线前拒绝。

s、v、a、j 必须由同一套解析式对转角求导、再乘 ω 的相应次方得到，禁止用相邻点差分冒充却在端点对不上闭式。转角为 0 时 s 为 0；转角为 β 时 s 为 h。摆线和余弦在两端速度为 0，摆线两端加速度也为 0。等加速在两端速度为 0，但加速度不为 0——这是该规律的已知性质，测试必须反映，不要偷偷改成两端加速度也是 0。等加速中点加速度变号，速度在中点连续。停歇段 s 保持 0 或 h，v、a、j 全为 0。回程把升程规律对位移做镜像：从 h 回到 0，端点连续性与升程相同。

只把 h 加大，全程 s、v、a、j 按同一比例放大。只把 β 加大、ω 不变，峰值速度下降。摆线的峰值加速度、峰值跃度必须对得上由 h、β、ω 写出的闭式。完整循环的转角网格从 0 走到一周，升程段、远休止、回程、近休止按调用方给的角度拼接；拼接角处位移必须连续，不允许在接头出现位移跳变。停歇角为 0 表示该段省略，不得因此把相邻两段的位移接错。

规律配方可登记：名字、类型、h、β。点名一条配方求升程曲线；也可以把完整循环（四段角度与各段类型）写成一条循环档再求一周。列出配方时给出类型与参数。启动时载入摆线升程一条：两端加速度为 0，终点位移等于 h。缺项、β 越界、未知类型，拒绝并说明原因。

用 Go 1.22 对外提供 HTTP。配方与循环档以本地文件保存。镜像用 golang:1.22-alpine 构建并跑单容器。无因次规律、乘 ω 还原量纲、循环拼接与连续性检查、档读写分成不同源文件，不要堆在一处。测试锁住：升程终点 s 等于 h、摆线两端 a 为 0、等加速中点加速度变号且终点仍为 h、等加速两端 a 不为 0、余弦两端 v 为 0、h 加大则曲线按比例放大、β 加大则峰值速度下降、未知规律被拒、接头位移连续、停歇段导数为 0。
